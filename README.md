# РОСГЛАВПИВО® — вёрстка сайта

Статический сайт: HTML, CSS и JavaScript без сборки и внешних runtime-зависимостей.

## Просмотр

Нужен Node.js 22 или новее:

```sh
npm install
npm run dev
```

Главная — `/`, страница «О конкурсе» — `/about.html`, «Экспертное жюри» — `/jury.html`, «Регистрация» — `/registration.html`, «Победители» — `/winners.html`, «Награды» — `/awards.html`, «Галерея» — `/gallery.html`, «Вопрос-ответ» — `/faq.html`, «Правовые документы» — `/legal.html`, «Политика обработки персональных данных» — `/policy.html` (локальный сервер также поддерживает `/about`, `/jury`, `/registration`, `/winners`, `/awards`, `/gallery`, `/faq`, `/legal` и `/policy`). Сервер слушает `0.0.0.0:3000`; порт можно изменить переменной `PORT`.

Для публикации достаточно статического HTTP-хостинга с HTML-файлами, `css/`, `js/`, `assets/` и `site.webmanifest`. Страницы используют общие `header.html` и `footer.html`, подгружаемые существующим `js/include.js`; поэтому открывать сайт нужно по HTTP, не через `file://`. Ссылки относительные — сайт может находиться в подпапке, например на GitHub Pages.

## Страница «О конкурсе»

- `about.html` — содержание по предоставленному PDF «Пиво Конкурс.pdf»: пять вводных абзацев, организаторы, три материала, комиссия и совет, видео, четыре высшие награды, 50+ стилей в 15 группах, преимущества, задачи, регистрационный CTA, блок «Поделиться», SEO-текст.
- `css/about.css` — дополнительные стили, ограниченные `.about-page`; главная и другие внутренние страницы не переоформляются.
- `js/about.js` — диалог материалов, подсветка текущего раздела, корректный отступ от шапки на мобильных, доступность аккордеонов и ссылки для публикации в соцсетях.
- Оформление, шрифты, фотографии, медали, повторяющиеся компоненты взяты из главной страницы исходного `master` (`4a858c0`). Ссылка на новую страницу добавлена в общий header/footer.
- Блок «Партнёры», отмеченный в PDF как скрытый, не выводится.

### Материалы для подключения перед публикацией

В репозитории нет файлов протокола, состава комиссии, трёх презентационных материалов и видео. На новой странице это обозначено явно: диалог сообщает о недоступности, кнопки скачивания неактивны. Никаких фиктивных PDF, загрузок или видеоплееров нет. Чтобы подключить материалы, замените соответствующие `data-about-material` на ссылки к опубликованным файлам; для видео вместо информационного диалога потребуется реальный источник и плеер. Фотографии в карточках — иллюстрации из существующих ассетов, не изображения слайдов презентаций.

В описании награды «Золотой стандарт» на новой странице указаны **три** золотые медали по PDF. На исходной главной было указано пять; её текст намеренно не менялся. Перед публикацией нужно согласовать это расхождение.

Кнопки регистрации ведут на новую страницу `registration.html#registration-form`. Короткая форма главной остаётся исходным компонентом и не заменяет полноценную регистрационную анкету. Прочие незаполненные ссылки общего меню относятся к исходной вёрстке и не означают наличие новых страниц.

## Страница «Экспертное жюри»

Завершающие блоки регистрации, публикации ссылки и SEO-текста повторяют оформление сайта.
- `css/jury.css` — адаптивная вёрстка, светло-золотой первый экран, навигационная карточка состава, портреты и хронологии. Другие страницы этим файлом не затрагиваются.
- `js/jury.js` — текущий пункт меню, отступ от фиксированной шапки, якоря с URL и переносом клавиатурного фокуса, ссылки публикации и копирование адреса.
- Пять фотографий взяты из имеющихся `assets/img/jury/`. Позиция председателя этапа «Выбор потребителя» в PDF не заполнена: по просьбе пользователя эта пустая позиция и связанная заглушка профиля не выводятся.
- Биографические сведения перенесены из предоставленного прототипа; независимая актуализация сведений не проводилась.
- Подключены переходы из общего header/footer, кнопок и имён экспертов на главной. Формулировка «50+ стилей пива» сохранена.

## Страница «Регистрация»

- `registration.html` — страница по PDF «Регистрация.pdf»: три шага участия, тарифы, 10 документов (3 от Координационного совета и 7 от Конкурсной комиссии), электронная анкета и контакты оргкомитета.
- `css/registration.css`, `js/registration.js` — адаптивная форма, динамические строки образцов, маска телефона, проверка обязательных полей, ИНН (10/12 цифр), e-mail, спирта от 0 до 100 с точкой; отдельные сообщения и сводка ошибок с переходом к полю.
- Список категорий включает все 53 имеющихся стиля в 15 группах. Публичная формулировка — «50+ стилей пива».
- Предварительный сбор считается по текущему периоду: 25 000 ₽ за образец, без неуказанной в PDF скидки. Расчёт не является счётом.
- Добавление/удаление сохраняет данные оставшихся образцов; последнюю строку удалить нельзя. Два согласия изначально не отмечены.
- Документы и ZIP пока отсутствуют: это явно указано, вместо несуществующей загрузки открывается информационное окно.
- Обновлены регистрационные ссылки в общем header/footer и CTA всех страниц.

**Это дизайн-вёрстка и демонстрация интерфейса, а не приём заявок.** Обработчика нет: анкета не отправляет сетевые запросы, не сохраняет персональные данные в localStorage/sessionStorage, не присваивает номера и не выставляет счета. Демоэкран прямо сообщает об этом; можно вернуться и отредактировать заполненную анкету. Без JavaScript кнопка отправки заблокирована.

Перед реальным запуском необходимо подключить серверный обработчик с серверной валидацией, защитой от спама, учётом согласий и безопасной обработкой данных, затем заменить демонстрационный сценарий и уведомления на реальную отправку. Отключение демоуведомления без реализации сервера не делает регистрацию рабочей. Также нужны реальные файлы документов и ZIP.

## Страница «Победители»

- `winners.html`, `css/winners.css`, `js/winners.js` — архив по PDF «Победители.pdf» в общей дизайн-системе. **Без таблиц, фильтров и реестра продукции**, как указано в прототипе.
- Девять сезонов в исходном порядке: 2026, 2025, 2024, 2023, 2021, 2020, 2019, 2018, 2017. 2022 год отсутствует в PDF и не добавлялся; результаты 2027 года не выдумывались.
- Для 2026 и 2025 годов сохранены описания мероприятий и по два видеоблока: награждение и «Ночь победителей». Остальные годы содержат только строку протокола.
- Реальные PDF-протоколы и видеофайлы/ссылки не предоставлены. «Открыть» показывает информационное окно с названием нужного материала, скачивание отключено. Видеоплеера без источника нет.
- Фото в видеоблоках — **иллюстрации из имеющегося фотоархива**, не подтверждённые кадры видеозаписей указанных лет. Это отмечено в карточках и диалоге; после получения реальных видео необходимо заменить иллюстрации их обложками и подключить плеер.
- Подключены ссылки в общем header/footer, регистрационный CTA ведёт на `registration.html#registration-form`. Поддерживаются прямые якоря `#season-2026` и другие существующие годы.

## Страница «Награды»

- `awards.html`, `css/awards.css`, `js/awards.js` — страница по трёхстраничному PDF «Награды.pdf» в стиле главной: четыре высшие награды с существующими изображениями, награды по категориям, материалы конкурса, регистрационный CTA, публикация страницы, SEO и общий подвал.

- Ссылки общего header/footer ведут на страницу, существующие ссылки «Подробнее о наградах» продолжают работать. Локальные якоря `#awards`, `#categories`, `#materials` учитывают высоту шапки; CTA ведёт на `registration.html#registration-form`.

## Полная галерея

- `gallery.html`, `css/gallery.css`, `js/gallery.js` — все **92 фотографии** из `assets/img/gallery/` на одной странице. Нет пагинации, фильтров, сворачивания и кнопки «Показать ещё»; список доступен сразу в HTML, в том числе без JavaScript.
- Общее количество фотографий не выводится в текстах, на карточках и в просмотрщике.
- Адаптивная сетка: 4 / 3 / 2 колонки. Миниатюры подгружаются по мере прокрутки через `loading="lazy"`, но сами карточки не скрыты. Новые изображения и выдуманные даты/описания мероприятий не добавлялись.
- Клик открывает большой снимок целиком в native dialog: номер текущего кадра без общего количества, предыдущий/следующий кадр, стрелки клавиатуры, горизонтальные свайпы, переход с последнего кадра на первый, ссылка на оригинал. Фокус удерживается внутри и возвращается к выбранной карточке после Escape/закрытия; позиция прокрутки сохраняется.
- Ошибка загрузки показывает сообщение и не блокирует переключение. Без JS ссылка ведёт прямо на большой JPG. Доступны прямые якоря `#photo-1` … `#photo-92`.
- Общие header/footer и обе ссылки «Вся галерея» / «Смотреть всю галерею» на главной ведут на `gallery.html`. Компактная подборка и прежний просмотрщик главной сохранены.

## Страница «Правовые документы»

- `legal.html`, `css/legal.css`, `js/legal.js` — по PDF «Правовые документы.pdf»: заголовок и подзаголовок, три строки документов, действия «Открыть / Скачать», публикация страницы, SEO и общий подвал. Регистрационный CTA не добавлен — в этом прототипе его нет.
- Порядок: политика обработки персональных данных, политика использования cookie, пользовательское соглашение. Ссылка «Правовые документы» в общем подвале ведёт на `legal.html`; поддерживаются `/legal` и якоря `#privacy`, `#cookie`, `#agreement`.
- В PDF-макете нет ссылок на реальные документы, в репозитории PDF-файлы отсутствуют. «Открыть» показывает название выбранного документа и контакт оргкомитета, скачивание отключено. Указанные в макете 280/120/190 КБ не выдаются за реальные размеры отсутствующих файлов.
- Это страница-каталог, **не составление или утверждение юридических текстов**. Перед публикацией нужны согласованные PDF и их реальные ссылки. `policy.html` — отдельная страница проекта политики; каталог ожидает утверждённых PDF, а не автоматически сгенерированного проекта.

## Политика обработки персональных данных

- `policy.html`, `css/policy.css`, `js/policy.js` — страница по структуре PDF «Политика обработки персональных данных.pdf». По просьбе пользователя сгенерирован текст всех **восьми разделов**: положения, цели, основания, категории данных, порядок обработки, cookie, права субъектов и контакты.
- **Проект для юридического и операционного согласования, не утверждённая политика.** Из материалов известен организатор конкурса, но статус оператора сайта, юридический адрес и реквизиты не подтверждены. Они не выдуманы. Нет обещаний о неподтверждённых серверах в РФ, отсутствии трансграничной передачи, конкретных мерах защиты или едином сроке хранения.
- Отражена текущая демоверсия: нет серверного приёма анкет, значения регистрационной формы находятся в памяти страницы. Описаны localStorage `rgp_cookie_ok` и `rgp_deadline_closed_v1`; они не названы cookie и не приравнены к согласию на рекламу/аналитику. Требования к будущей обработке отделены от фактических функций интерфейса. Текст не заменяет отдельное согласие.
- Контакт оргкомитета и адрес проведения конкурса взяты с сайта; адрес проведения явно не выдан за адрес оператора. До запуска нужно определить оператора, инфраструктуру и обработчиков, локализацию/передачу, цели/основания/сроки, порядок обращений и удаления, состав согласий и уведомлений. Баннеры и согласия остальных старых страниц требуют отдельной юридической проверки.
- Работают оглавление, прямые якоря (включая существующий `#cookie`), фокус и мобильная вёрстка. Исправлена ссылка политики в информационном блоке общего подвала; регистрационные ссылки сохранены.
- `assets/docs/personal-data-policy-draft.pdf` — **реальный PDF проекта**, пять страниц, тот же текст с отметкой статуса. На странице можно открыть и скачать проект; утверждённый PDF в правовом каталоге по-прежнему не имитируется. Сервер отдаёт PDF с корректным MIME.
- После правок HTML обновить PDF: при запущенном `npm run dev` выполнить `node scripts/export-policy.mjs` (можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`). Print-стили исключают меню, SEO, плавающие кнопки и другие элементы сайта.

npx playwright install --with-deps chromium
